# Architecture

These files describe the current released architecture:

- `CodexArchitecture.md`: package capabilities and dependency direction.
- `CodexTargetTopology.md`: products, targets, and transport roles.
- `CodexSDKArchitecture.md`: thread and turn API semantics.
- `CodexAppServerArchitecture.md`: generated protocol, client, and transports.
- `CodexExecArchitecture.md`: direct `codex exec` process contract.
- `CodexMCP.md`: `codex mcp-server` lifecycle and tool calls.
- `CodexMCPContracts.md`: MCP protocol invariants and error handling.

Historical planning notes are intentionally not part of the public release
tree. Keep these documents aligned with observable code and tests.
